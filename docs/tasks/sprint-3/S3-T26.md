# Add Student Preferences validation regression tests

## Description

Expand backend unit test coverage for invalid Student Preferences requests.

## Specs

- Test fractional study durations.
- Test empty available weekday arrays.
- Test missing required fields.
- Test identical start and end times.
- Verify invalid inputs throw BadRequestException.

## Requirements

- Use Vitest for backend unit tests.
- Reuse the existing preferences validation function.
- Do not require PostgreSQL.
- Preserve existing API behavior.
- Ensure existing tests continue passing.
- Ensure backend TypeScript typechecking succeeds.

## Acceptance criteria

1. New regression tests cover all specified invalid inputs.
2. Invalid inputs produce BadRequestException.
3. All backend tests pass.
4. TypeScript typechecking succeeds.
